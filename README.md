**CampusMate AI (Group Project)** – Intelligent College Information & Student Support System | **React.js, Vite, FastAPI, Python, PostgreSQL, Groq API, GPT-OSS 120B, JWT**

- Developed an **AI-powered college assistance chatbot** supporting academic queries, official college information, library services, canteen facilities, co-curricular activities, and campus navigation.
- Implemented **student and administrator authentication**, JWT-based authorization, password recovery through email, and persistent conversation history.
- Built a **React.js and Vite frontend with a FastAPI backend**, integrating PostgreSQL for user data and chat history management.
- Integrated the **Groq API with the GPT-OSS 120B model** to provide AI-powered conversational responses.
- Designed **role-based workflows** and integrated the **Brevo API** for automated password-reset emails.
- Deployed the application using **Vercel (frontend) and Render (backend)**.
